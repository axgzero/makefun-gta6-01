**Solmarina** — an original open-world crime game built for make.fun's "Make GTA 6" bounty. A golden-hour coastal city, fully explorable on foot or behind the wheel: steal cars, outrun the Solmarina PD as your wanted level climbs to five stars, and run five story missions for fixer Mara Solís — from your first stolen sports car to a dockside shootout with the Tiburones and a vault heist worth $2,500. Traffic, pedestrians, police chases, pistol combat, a live minimap, and a save that persists between sessions — all in one offline HTML page, with every texture, sound, and song generated procedurally in code. Nothing here comes from Rockstar or GTA: the city, the characters, and the story are all original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game plays fully offline.
